# Personal Expense Tracker

## Project Goal
The Personal Expense Tracker is a simple Java command-line application that helps users manage their everyday expenses. Users can record expenses, view their spending history, and calculate their total spending.

## MVP Features
- Add a new expense with a name, amount, and category.
- View all recorded expenses.
- Calculate total spending.
- Save expenses to a text file.

## Future Plans
- Edit existing expenses.
- Delete expenses.
- View monthly spending summaries.

## Tech Stack
- Language: Java
- Libraries: Java standard libraries
- Data Storage: expenses.txt
- Development Tools: VS Code or IntelliJ IDEA
- External APIs: None

## Project Structure
- src/ — Java source code
- docs/ — Project documentation and system diagram
- expenses.txt — Saved expense data
